Step 2: Terminal orientation

About 10 minutes. From day 2 you read output in a terminal, so learn the few moves you will need now. You only read and look; nothing here changes the lab.

Open your terminal

Open the Bitcoin lab. It gives you your own terminal in the browser, running a tool called zellij that splits one window into panes.

If the lab will not start, read the saved output below and tell your instructor. Your instructor can check the same things from it.

Move around

Type each command, press Enter and read what comes back.

pwdWhere you are. It prints /home/user.
lsWhat is here. ls -a also shows hidden items such as .bitcoin.
cd scripts, then cd ..Go into a folder, then back up one level.
cat and lessless ~/.bitcoin/debug.log opens the node's log in a viewer: arrows move, q quits.
grep "text" fileFinds lines containing text: grep "error" ~/.bitcoin/debug.log.

Avoid rm. It deletes for good, and nothing in this step needs it.

Read the node

The lab runs a Bitcoin node. Ask it about itself:

bitcoin-cli -datadir=/home/user/.bitcoin getblockchaininfo | jq

jq lays the answer out so you can read it. It is a block count and a chain name, not a paragraph to memorize.

Panes and scrolling

Ctrl+GSwitches between typing into the shell and giving zellij a command.
Ctrl+G, p, rSplit the window into a left and right pane.
Alt+arrowMove between panes.
exitClose the pane you are typing in.
Ctrl+G, sScroll mode: arrows or Page Up and Down read what has gone by. Ctrl+G returns.

The terminal does not scroll like a web page, so use scroll mode.

The full guide is PRIMER.md in the lab files.

The questions you answer

Show your instructor your screen as you answer.

1. What does pwd print, and which hidden folder holds the node's data?

2. Run the getblockchaininfo command. What chain is the node on, and how many blocks does it have?

3. Split the window, run ls in the new pane, and close it again.

4. Scroll up to the start of the getblockchaininfo output. How did you get there?
