Wallet page: seed phrase to addresses

This page does what a wallet does when you restore it from a seed phrase: it turns the phrase into a master key, derives keys down a path, and turns each public key into an address. Everything runs in your browser; the page sends nothing anywhere.

The phrases in this lab come from published test vectors. They guard nothing and exist only on this training chain. Never type a real seed phrase into a web page.
