💡 How to View & Render Slide Decks

Why did "ERR_FILE_NOT_FOUND" occur?

When you open mindmap.html directly from your file manager (file:///), the links look for compiled .html files. However, this curriculum is authored in Quarto Markdown (.qmd). Quarto compiles them into interactive RevealJS presentations only when rendered or served via HTTP.

🌐 Option 1: View Online via GitHub Pages (Recommended)
  1. Open your GitHub repository (astevegreen/blockchain-technology-course).
  2. Go to Settings → Pages and set the Source to GitHub Actions.
  3. Go to the Actions tab, click Publish Course to GitHub Pages (Manual), and click Run workflow.
  4. Once built, the entire course and all slides are live at https://astevegreen.github.io/blockchain-technology-course/.
  5. In this mind map, set Slide Server to GitHub Pages to jump directly to any slide.
💻 Option 2: Live Local Dev Server with Quarto
  1. Install Quarto via terminal: winget install Posit.Quarto or download from quarto.org.
  2. In your terminal inside this repository, run:
    quarto preview blockchain-course
  3. Quarto automatically renders all lessons and serves them at http://localhost:9001/.
  4. In this mind map, set Slide Server to http://localhost:9001/.
🖥️ Option 3: Local Python HTTP Server

If the site has been rendered to blockchain-course/_site:

python -m http.server 8000 --directory blockchain-course/_site
