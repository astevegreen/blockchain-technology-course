Course Labs: read me first

This folder starts the course labs on your own computer. Your work stays on your computer.

1. Your computer will warn you the first time

The file Start Course Labs is not signed with a paid certificate, so Windows and macOS warn you once. That is expected. Open it only from the course zip you downloaded from the link your instructor gave you.

Windows

  1. Double-click Start Course Labs.
  2. If a blue box says Windows protected your PC, press More info.
  3. Press Run anyway.

Mac

  1. Double-click Start Course Labs. macOS says it cannot verify the file. Press Done.
  2. Choose Apple menu, then System Settings, then Privacy & Security. Scroll down to Security.
  3. Press Open Anyway, type your Mac password and press OK. The button is there for about an hour after the first try.

2. You need Docker Desktop once

Docker Desktop is the free program that runs the labs. If it is not installed, Start Course Labs opens the guide for you. Install it, open it, wait until it says it is running, and double-click Start Course Labs again. Windows needs Windows 11 version 23H2 or newer; a Mac needs a recent macOS. Full steps are in the guide below.

3. Use the labs

  1. Double-click Start Course Labs. Your browser opens the control page at http://127.0.0.1:8470/.
  2. Press Start next to a lab. The first time it downloads, which can take a few minutes, or longer for the big labs.
  3. When the card says Running, press Open.
  4. When you finish for the day, double-click Stop Course Labs. Your work is kept.

Reset deletes your work in that lab. Use Stop to finish for the day.
